# ربحي - دليل التشغيل (النسخة السحابية)

## التطبيق جاهز (APK)
- `app-debug.apk` — ثبّته على أي هاتف وأنه يعمل من أي مكان بالعالم.

## السيرفر
الخادم يعمل على سحابة Render (مجاني) وعنوانه العام:
- **https://rebhi-server.onrender.com**
- البيانات تُحفظ على السيرفر في `server/data/rebhi-data.json`

ملاحظة: خطة Render المجانية تُعيد تشغيل عند الخمول؛ عند إعادة الاستقرار البيانات في ملف JSON تبقى، لكن عند إعادة النشر/الحذف قد تُمحى. لتخزين دائم فعلياً استخدم قاعدة بيانات سحابية (يمكن إضافتها لاحقاً).

## حساب المدير
- البريد: `admin@rebhi.dz`
- كلمة السر: `Admin@2026`
- الدخول للمدير: في شاشة تسجيل الدخول اضغط شعار "ربحي" 5 مرات خلال 3 ثوانٍ.

المدير يستطيع:
- الموافقة/رفض طلبات السحب
- إيقاف/إلغاء إيقاف المستخدمين
- إدارة كلمات الفلترة الممنوعة (قمار / +18)
- رؤية سجل التدقيق (audit log)

## إعادة البناء بعد تعديل الواجهة
```bash
# 1) عدّل API_BASE في www/index.html
# 2) مزامنة + مزامنة شكلي:
npx cap sync android
# 3) خفّض مستوى Java في ملفين (بسبب JDK 17):
#   android/app/capacitor.build.gradle  -> VERSION_17
#   node_modules/@capacitor/android/capacitor/build.gradle -> VERSION_17
# 4) ابنِ:
cd android
gradlew.bat assembleDebug
```
