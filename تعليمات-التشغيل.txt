# ربحي - دليل التشغيل

## 1. تشغيل السيرفر (على الكمبيوتر)
```bash
cd server
npm start
```
يستمع على المنفذ 3000 لجميع الأجهزة على الشبكة.

البيانات تُحفظ في: `server/data/rebhi-data.json` (ليست على الهاتف، على السيرفر فقط).

## 2. تثبيت التطبيق على الهاتف
- انسخ ملف `app-debug.apk` إلى الهاتف وثبّته.
- تأكد أن الهاتف متصل بنفس شبكة الواي فاي للمستخدم.

### عنوان السيرفر
التطبيق يتصل بـ `http://192.168.5.30:3000/api`.
إذا تغيّر عنوان IP للكمبيوتر، حدّثه في `www/index.html` (سطر API_BASE) ثم أعد البناء:
```bash
npx cap sync android
cd android
gradlew.bat assembleDebug
```

## 3. حساب المدير
- البريد: `admin@rebhi.dz`
- كلمة السر: `Admin@2026`
- الدخول للمدير: في شاشة تسجيل الدخول اضغط على شعار "ربحي" 5 مرات خلال 3 ثوانٍ.

المدير يمكنه:
- الموافقة/رفض طلبات السحب
- إيقاف/إلغاء إيقاف المستخدمين
- إدارة كلمات الفلترة الممنوعة (قمار / +18)
- مشاهدة سجل التدقيق (audit log)

## 4. فلترة المحتوى
الخادم يرفض تلقائياً أي محتوى يحتوي كلمات ممنوعة (قمار، كازينو، رهان، بورنو، جنس، ...) في اسم المستخدم أو بيانات الحساب. يمكن إضافة/حذف الكلمات من لوحة المدير.
